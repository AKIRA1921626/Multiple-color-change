# Multiple-color-change
複数の色を指定して変更するAviutl2用のスクリプト  
「色調整」に表示される。  
「変更前色」を指定すると、それが「変更後色」に変換される。  
「指定色複数変更」スクリプトでは、変更前色1-6がすべて変更後色に変換される。  
「指定色複数変更（個別）」スクリプトでは、変更前色1~6が、それぞれの項目でしていた変更後色1-6にそれぞれ変更される。  
どちらも「色1赤緑青(±)」などを調整すれば、「変更前色」がどの程度変換されるかを調整できる。  
また、「変換後処理」の項目の、単色化、色反転、クロマキーで、「変換前」に指定した色を、透過したりなども選ぶことができる。  
二次配布可、改変可、クレジット不要
